## 📱 About

**Hide-Keyboard** is an Android application for users who want more control over the on-screen keyboard.

The project is intended for Android devices running Android 5.0 and newer.

## ✨ Features

* ⌨️ Helps hide the on-screen keyboard.
* 📱 Designed for Android devices.
* 🔧 Open-source project.
* 📦 APK available for direct installation.
